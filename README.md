# HCI Deep Dives — audio

Episode audio for [HCI Deep Dives](https://www.deep-hci.org), stored as **release
assets**, one release per year (`audio-2024`, `audio-2025`, …). Nothing but this
README is tracked in git.

The RSS feed at <https://www.deep-hci.org/feed.xml> links straight to these assets,
so **renaming or deleting a release or an asset breaks published episodes.** Add new
files with `publish_episode.py` in
[geist-publishing/deep-hci](https://github.com/geist-publishing/deep-hci).
